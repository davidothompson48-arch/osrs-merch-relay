# OSRS Merch Relay

Hourly transport/cache for Old School RuneScape Grand Exchange market data sourced exclusively from the RuneLite-fed OSRS Wiki real-time price API at `prices.runescape.wiki`.

The generated `snapshot.json` is consumed by the ChatGPT OSRS Merch Desk. GitHub is only the transport layer; it is not a substitute market-data source.
